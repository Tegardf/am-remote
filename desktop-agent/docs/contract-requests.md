- [x] Say that `artist` and `album` are separate, and how Apple Music's merged value is handled - why: Apple Music for Windows reports `"Artist — Album"` in SMTC's artist field and an empty album (verified with `examples/read_player.rs`) - default used: if the album is empty and the artist contains `" — "` (space, em dash, space) it is split at the first one (`split_artist_album` in `src/media/state.rs`); anything else passes through (MVP 2, 2026-11-14)

- [x] State when `artwork_rev` increments - why: the contract only says "when artwork changes" - default used: on every track change (even with identical art), when the cover of the same track appears late, and when Apple Music quits; never for pause, resume, seek or volume (`ArtworkCache` in `src/media/state.rs`) (MVP 2, 2026-11-14)
